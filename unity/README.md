# Kalyeah on Unity

Unity 6 LTS (`6000.0.86f1`, URP, Android `arm64-v8a` IL2CPP + headless `.NET 8` server) port of the Godot 4.6 game. The Godot project at the repository root remains the single source of authored art and `.tres` balance data; everything imported into Unity is synced or generated by code rather than hand-edited YAML.

## Asset, data & package sync (`sync_assets.py`)

Run before opening `unity/Game` or running Unity batchmode builds/tests:

```bash
tools/unity_export/sync_assets.sh        # delegates to sync_assets.py when Python >= 3.8 is available
python tools/unity_export/sync_assets.py # cross-platform (Windows / macOS / Linux)
```

`tools/unity_export/sync_assets.py` populates git-ignored directories under `unity/Game/` while preserving Unity `.meta` files and pruning stale files:

- **Art & `.webp` -> `.png` conversion:** mirrors `assets/models/{characters,barangay,props,weapons}`, `textures`, `audio`, `fonts`, `ui`, `icons`, and `portraits` into `Game/Assets/Imported/Resources/`, converting all `.webp` UI/card/icon/portrait textures into RGBA `.png` via Pillow (`pip install Pillow`, with `ffmpeg`/`dwebp` fallback) so `Resources.Load<Texture2D>` and `Sprite` load them directly.
- **Data & localization:** copies `unity/Data/*.json` (39 exported rule, weapon, character, bot, camera, net, and street-game resources) plus `data/i18n/strings.csv` (`i18n__strings.csv`) into `Game/Assets/Imported/Resources/Data/`.
- **Embedded shared C# package:** mirrors `unity/Kalyeah.Sim` (`Runtime/`) and `unity/Kalyeah.Net` (`Net/`) into `Game/Packages/com.kalyeah.sim/` (`v1.0.0`, enabling `KALYEAH_SIM_PORTED` via `versionDefines`).

Regenerate `unity/Data/*.json` and `unity/Golden/**` after changing a rule in the Godot project:
`godot --headless --path . -s tools/unity_export/export.gd` (and `tools/unity_export/export_net.gd` for wire goldens).

## Assembly layout

### Engine-free `.NET 8` & embedded package (`unity/Kalyeah.sln`)
- **`Kalyeah.Sim`** (`unity/Kalyeah.Sim/`, `Kalyeah.Sim.asmdef`, `noEngineReferences: true`): deterministic 30 Hz 5v5 *Agawang Base* simulation (`MatchSim`, 16 weapons, objectives, status effects), `BarangayNav` A*, bots (`DummyBrain`, `FightBrain`, `TeamBrain`, `TeamCoach`), `RankedSystem`, `BalanceDuel`, `GodotRng`, `Vec2`/`Rect2` math, `SimData` JSON loader, and the 3 *Larong Kalye* street modes (`Patintero`, `TumbangPreso`, `LangitLupa`, `StreetModeCoach`).
- **`Kalyeah.Net`** (`unity/Kalyeah.Net/`, `Kalyeah.Net.asmdef`, `noEngineReferences: true`): byte-compatible Godot `VariantCodec` wire framing, 10-slot `RoomService`, authoritative `ServerMatch` & `GameServer`, `GameClient` mirror/snapshots, `StreetWire`, IL2CPP-safe WebSocket client/server (`WsClientTransport`, `WsServerTransport`), and LAN Hotspot discovery (`HotspotNet`, `HotspotBeacon`, `WifiQr`).
- **`Kalyeah.Server`** (`unity/Kalyeah.Server/`): standalone headless WebSocket + HTTP health-check (`200 kalyeah`) dedicated server (`PORT=8080 dotnet run --project unity/Kalyeah.Server`).
- **`Kalyeah.Sim.Tests` & `Kalyeah.Net.Tests`**: NUnit test suites verifying sim rules, bots, street modes, rooms, snapshots, and wire parity against Godot golden recordings (`unity/Golden/`).

### Unity 6 project (`unity/Game/Assets/Kalyeah/`)
- **`Kalyeah.Game.Core`** (`Scripts/Kalyeah.Game.Core.asmdef`, `noEngineReferences: true`, refs `Kalyeah.Sim`, `Kalyeah.Net`): engine-free game bridge — `SimBridge` (local 5v5 practice/training + `GameClient` online/hotspot mirror), `StreetBridge` (*Patintero*, *Tumbang Preso*, *Langit Lupa* offline bots + online wire), `AppSession` (selected kid, 3-superpower loadout, game mode, ranked history, active client/server/room state), `SettingsStore`, `GameData`, `GodotSpace` (`sim (x, z)` -> Unity `(x, 0, -z)`, yaw `180° - θ`), and `BarangayPlan`.
- **`Kalyeah.Game`** (`View/Kalyeah.Game.asmdef`, refs `Kalyeah.Game.Core`, `Kalyeah.Sim`, `Kalyeah.Net`, `Unity.InputSystem`, `UnityEngine.UI`, URP): 3D barangay world & URP shaders (`MatchView`, `BarangayEnvironmentBuilder`, `SpaghettiWiresBuilder`, `BarangayCurbsAndProps`, `ObjectiveZonesView`, `KidView` with team ink outlines and zero foot rings), `ShoulderCamera` + `AimSolver`, zero-GC pooled `FxPool` / `AudioHub` / `Haptics`, responsive touch & tilt HUD (`MatchHud`, ability arc/cards, `VirtualJoystick`, `LookPad`, `SafeArea`, `ScreenFitMetrics`, `TiltInput`), menus/lobby/street views, and `link.xml` preserving `Kalyeah.Sim` + `Kalyeah.Net` under IL2CPP.
- **`Kalyeah.Editor`** (`Editor/Kalyeah.Editor.asmdef`, Editor-only): `KalyeahBuild` (`Setup`, `BuildAndroid`, `Screenshots`) and `KalyeahAndroidManifest` (landscape auto-rotation, `arm64-v8a` IL2CPP, min SDK 24 / target SDK 35, minimal Android permissions).
- **`Kalyeah.Tests.EditMode`** (`Tests/EditMode/Kalyeah.Tests.EditMode.asmdef`, Editor NUnit): Unity EditMode suite checking synced `Resources`/`.png` textures, data parity, `SimBridge`/`StreetBridge` contracts, and multi-aspect HUD/safe-area bounds.

## Game modes: Online, LAN Hotspot & Street (*Larong Kalye*)

- **Practice & Training (offline 5v5 *Agawang Base*):** `SimBridge` steps local `MatchSim` at 30 Hz with `easy`/`medium`/`hard` `TeamBrain`/`TeamCoach` bots (or stationary training dummies) and the player's cosmetic kid + superpower loadout.
- **Online rooms:** `AppSession` connects `GameClient` over WebSocket (`WsClientTransport`) to `Kalyeah.Server` (or the Godot dedicated server), manages 10-slot room codes (`CreateRoom`, `JoinRoom`, team swap, ready, start), sends `PlayerInput` each tick, and renders `client.Mirror`.
- **LAN Hotspot:** `HotspotNet` runs an authoritative in-app `GameServer` (`WsServerTransport` over managed `TcpListener` — no `HttpListener`) advertised on the local subnet via UDP `HotspotBeacon` and `WifiQr` QR/NFC join payloads (`kalyeah_local` permissions).
- **Street modes (*Larong Kalye*):** `StreetBridge` drives *Patintero* (grid-line crossings vs line taggers), *Tumbang Preso* (slipper throws, can knockdown/reset, and *taya* chase), and *Langit Lupa* (elevated safe platforms, raising mounds, brownout phase, and *taya* tag) offline with `StreetModeCoach` bots or online via `StreetWire`.

## Testing & dual-aspect screenshots

- **`.NET 8` sim + net suites (no Unity licence required):**
  `dotnet test unity/Kalyeah.sln --configuration Release`
- **Unity EditMode tests (after `sync_assets`):**
  `Unity -batchmode -projectPath unity/Game -runTests -testPlatform EditMode -testResults build/editmode-results.xml -quit`
- **Dual-aspect visual captures (`KalyeahBuild.Screenshots`):**
  `Unity -batchmode -projectPath unity/Game -executeMethod KalyeahBuild.Screenshots -quit` (run **without `-nographics`**; wrapped in `xvfb-run` on Linux CI). Renders deterministic PNGs into `unity/Game/Build/screenshots/` across both mobile landscape gates: **`1280×720`** (`16:9` base) and **`844×390`** (`~19.5:9` notched phone with simulated safe-area cutout) covering menus, 5v5 shoulder-camera spots + HUD, and street modes.
- **Open locally in Unity Hub:** run `python tools/unity_export/sync_assets.py`, open `unity/Game` in Unity `6000.0.86f1` (with Android Build Support), click *Kalyeah > Setup Project*, and play `Assets/Kalyeah/Generated/Scenes/Title.unity`.

## CI (`.github/workflows/unity.yml`) & licence secrets

Triggered on pushes touching `unity/**`, `tools/unity_export/**`, or `.github/workflows/unity.yml`, plus `workflow_dispatch`:

1. **`sim-tests`:** runs `dotnet test unity/Kalyeah.sln` (always runs; needs no Unity secrets).
2. **`unity-check`:** reads `ProjectVersion.txt` and checks `UNITY_EMAIL`, `UNITY_PASSWORD`, and `UNITY_LICENSE` (or `UNITY_SERIAL`); skips the Unity jobs cleanly with a notice when unset.
3. **`editmode-tests`:** ensures `Pillow`, runs `tools/unity_export/sync_assets.sh`, and executes `game-ci/unity-test-runner@v4` (`EditMode`).
4. **`android`:** ensures `Pillow`, runs `sync_assets.sh`, builds `KalyeahBuild.BuildAndroid` (`arm64-v8a` APK), verifies `lib/arm64-v8a/*.so` ABI presence and logs APK size in MB (no artificial size cap), and uploads `kalyeah-unity-apk`.
5. **`screenshots`:** ensures `Pillow`, runs `sync_assets.sh`, renders `KalyeahBuild.Screenshots` under `xvfb`, and uploads `kalyeah-unity-screenshots`.

**Repository secrets** (*Settings > Secrets and variables > Actions*, see <https://game.ci/docs/github/activation>):
- `UNITY_EMAIL` & `UNITY_PASSWORD`: Unity account credentials (without 2FA challenge blocking headless sign-in).
- `UNITY_LICENSE`: full contents of `Unity_lic.ulf` from Unity Hub (`C:\ProgramData\Unity\Unity_lic.ulf` on Windows, `/Library/Application Support/Unity/Unity_lic.ulf` on macOS, `~/.local/share/unity3d/Unity/Unity_lic.ulf` on Linux), or `UNITY_SERIAL` for Pro/Plus.
